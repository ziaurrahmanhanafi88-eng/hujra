# حجره — د نظرونو ټولنیز سایټ

> "هرچا خبره، یوه حجره" — یو ساده، ښکلی او خپلواک ټولنیز ویب پاڼه چې خلک وکولی شي خپل نظر (متن) او عکسونه خپاره کړي، او د بل چا خبرې "خوښې" کړي.

دا یوه **بشپړه ستاتیک (static) ویب پروژه** ده — هیڅ سرور ته اړتیا نشته، مستقیم د GitHub Pages له لارې خپرېدلی شي.

## 📁 فایلونه

```
hujra/
├── index.html              ← اصلي پاڼه (ننوتل + فيډ + پروفایل)
├── style.css                ← ډیزاین (رنګونه، فونټونه، انیمیشن)
├── script.js                 ← ټول منطق (حساب جوړول، پوسټ، لایک)
├── google-auth-config.js     ← ستاسو د جیمیل Client ID دلته کیږدئ
└── README.md
```

## ▶️ په خپل کمپیوټر کې چلول

هیڅ نصبولو ته اړتیا نشته. یوازې `index.html` فایل په براوزر کې پرانیزئ، یا د اسانتیا لپاره یو کوچنی سرور وچلوئ:

```bash
# که پایتون نصب وي
python3 -m http.server 5500
# بیا په براوزر کې: http://localhost:5500
```

## ✅ اوس مهال څه کار کوي

- **بریښنالیک + پټنوم سره حساب جوړول او ننوتل** — په بشپړ ډول کار کوي (د براوزر `localStorage` کې خوندي کیږي).
- **د نظر (متن) او عکس خپرول** — عکس په اتومات ډول کوچني او فشرده کیږي چې ساحه ونه ډکوي.
- **لایک (🔥ورین) کول** — هر کارن کولی شي هره خبره خوښه یا بېرته لرې کړي.
- **زما پاڼه** — یوازې ستاسو خپاره شوي نظرونه ښیي.

## 🔐 د ریښتیني جیمیل (Google) ننوتلو فعالول

اوسمهال د "جیمیل سره ننوتل" تڼۍ یوازې هغه وخت ښکاره کیږي/کار کوي چې تاسو خپل ریښتینی Google Client ID ورکړئ (دا د امنیت لپاره اړینه ده — هیڅ عمومي کوډ دا نشي کولی):

1. لاړ شئ [Google Cloud Console](https://console.cloud.google.com/apis/credentials) ته.
2. یو نوی project جوړ کړئ.
3. **Create Credentials → OAuth client ID → Web application** غوره کړئ.
4. د خپل سایټ اډرس (لکه `https://yourusername.github.io`) د **Authorized JavaScript origins** لاندې ورزیات کړئ.
5. ستاسو ورکړل شوی Client ID کاپي کړئ او دا په `google-auth-config.js` کې کیږدئ:
   ```js
   const GOOGLE_CLIENT_ID = "ستاسو-client-id.apps.googleusercontent.com";
   ```
6. پاڼه بیا پورته (reload) کړئ — اوس به ریښتینی د Google تڼۍ ښکاره شي.

## 🚀 ته GitHub خپرول

```bash
cd hujra
git init
git add .
git commit -m "حجره — لومړی نسخه"
git branch -M main
git remote add origin https://github.com/<ستاسو-یوزرنیم>/hujra.git
git push -u origin main
```

بیا د **GitHub Pages** فعالولو لپاره: ریپوزیټری کې `Settings → Pages → Branch: main → Save` کړئ. ستاسو سایټ به دلته وي:
`https://<ستاسو-یوزرنیم>.github.io/hujra/`

## ⚠️ مهم یادونه

دا نسخه ډاټا (کارنان، پوسټونه) یوازې په **هر براوزر کې محلي ډول (localStorage)** خوندي کوي — یعنې که بل چا ستاسو د سایټ لینک په بل کمپیوټر کې پرانیزي، هغه به ستاسو پوسټونه ونه ویني (هرڅوک خپل جلا ډاټابیس لري). که تاسو غواړئ ټول کاروونکي یو ګډ فيډ وویني (ریښتینی ملټي-یوزر ټولنیز سایټ)، بیا به اړتیا وي یوه ریښتیني بیک-اند خدمت (لکه Firebase, Supabase, یا خپل سرور) ورسره وصل کړئ — چې زه هم کولی شم مرسته درسره وکړم که وغواړئ.
